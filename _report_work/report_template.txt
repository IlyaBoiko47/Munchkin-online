Введение
Целью практики было получение практического опыта работы на предприятии и закрепление теоретических знаний, полученных в учебном заведении. Для выполнения этой цели был заключен договор с предприятием ООО «ТомИУС-ПРОЕКТ». Основными направлениями деятельности на предприятии являются проектирование, производство и внедрение высокоэффективных информационно-управляющих систем (ИУС) и автоматизированных систем управления технологическими процессами (АСУТП) для различных отраслей производства, разработка и производство высокотехнологичных микроэлектронных устройств и приборов, построенных на современной элементной базе. .
Для прохождения практики в организации ООО «ТомИУС-ПРОЕКТ» была поставлена цель разработать модуль для отображения справочников и их содержания из заранее заданных баз данных. Для выполнения этой задачи нужно было проделать объем работы, включающий несколько этапов:
Подготовка окружения: на этом этапе требовалось подобрать и установить необходимое программное обеспечение на выбранную машину, в данном случае – Персональный компьютер. Большую часть требуемого ПО можно определить по заданным условиям выполнения задания.
Изучение структуры проекта: После настройки окружения необходимо изучить структуру проекта и уникальные черты работы с фреймворком Qt. Так как работа с фреймворком Qt проводится впервые, а информация о структуре проекта, используемого для выполнения задания, ограничена, а этот этап потребуется затратить наибольшее количество времени.
Разработка кода компонентов для отображения справочников: Важным аспектом является корректное написание кода компонентов модуля. При неправильной  структуре компонентов будет невозможно будет обеспечить их взаимодействие с уже существующими компонентами проекта.
Составление отчета: По завершении всех технических этапов проекта нужно было подготовить подробный отчет, в котором были бы описаны все выполненные работы, использованные методы и полученные результаты. Отчет включал бы в себя также анализ проделанной работы и возможные рекомендации для дальнейшего улучшения системы.
Процесс выполнения этих задач позволил мне получить ценные практические навыки, а также углубить свои знания в области разработки на C++ и в фреймворке Qt.
Выполнение задания проводилось дистанционно, в следствие чего инструктажи по безопасности проходить не потребовалось.
Разработка кода компонентов для отображения справочников
Первым заданием на практике стала установка необходимого ПО. Сперва был установлен фреймворк Qt, который использовался при создании изначального проекта для выполнения задания.
Так как работа над проектом происходит коллективно с другими участниками практики необходимо также установить компоненты для подключения к GitHub, после чего подключится к созданному ранее репозиторию проекта.
Помимо установления подключения к репозиторию GitHub и установки фреймворка Qt необходимо также скачать дополнительные файлы на ПК, содержащие базы данных, файлы проекта, а также настроечные файлы. 
Рис. 2 — Файлы проекта.
Далее необходимо запустить сервер для проекта локально на устройстве, что можно сделать воспользовавшись программой SQL Server Management studio, предоставленной вместе с файлами проекта.
Рис. 3 — Восстановление БД.
После запуска сервера, необходимо “восстановить” базы данных, используя .bak файлы, также предоставленные вместе с проектом. Для каждой из восстановленных БД необходимо создать ODBC соединение, используя встроенные инструменты Windows. 
Рис. 4 — Созданные ODBC соединения
В каждом созданном соединении необходимо провести настройку, указав ранее созданный экземпляр подключения, а также БД, взятую за основу и данные для установления соединения.
Рис. 5 – 7 — Настройка ODBC соединения.
 После завершения создания соединений с БД, необходимо  также изменить настроечный файл проекта suik.ini.
Необходимо изменить названия ODBC соединений на те, что были указаны при их создании на локальном устройстве, а также указать путь к папкам с файлами для сборки проекта.

Рис. 9 — Успешная авторизация
После завершения настройки среды разработки можно приступить к разработке приложения.
В данном случае для разработки дизайна компонента был выбран встроенный в Qt язык разметки – qml, для механической части приложения же был выбран язык C++. 
Было решено сделать отображение справочников отдельным окном. 
Рис. 10 — Созданный дизайн окна.
По завершению создания дизайна, ожидалось написание бэк-энд составляющей от второго участника задания для подключения к БД и получения из неё всех необходимых данных. Так как второй участник задания не справился со своей частью, продолжение выполнения задания является невозможным.
Заключение
В результате прохождения практики был получен опыт работы в фреймворке Qt, в частности, написания фронтенд составляющей приложения, а также её подключения с бэкенд составляющей.
Был получен опыт в создании локальной базы данных, а также подключению к ней с использованием ODBC соединения. 
Самое главное, была получена возможно изучить структуру и устройство потенциального коммерческого проекта и оценить собственные навыки в работе с проектом, без доступа к документации.
Несмотря на все приложенные усилия задание не получилось завершить, в частности, из-за невыполнения второго участника задания своих задачь.
Однако, работа с проектом принесла незаменимый опыт в взаимодействии с коммерческими разработками.
